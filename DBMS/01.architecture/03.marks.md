### 💡 Section 3: 3 Marks (Conceptual Breakdown)

#### Q1. Explain 1-Tier setup with a railway computer example.
---------------------------------------------------------------------------------------------
* The booking software and database files are installed on a single PC.
* The booking clerk triggers queries and updates records locally on it.
* The system prints tickets without any network or external server connection.
---------------------------------------------------------------------------------------------

#### Q2. Explain E-commerce workflow in 3-Tier Architecture.
---------------------------------------------------------------------------------------------
* User Tier: The consumer visits the app and adds a product to the cart.
* Application Tier: The middle server checks stock and calculates final price.
* Database Tier: The validated order history is stored safely in the database.
---------------------------------------------------------------------------------------------

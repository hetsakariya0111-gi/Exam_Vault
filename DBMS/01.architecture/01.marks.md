### 🎓 Section 1: 1 Mark (MCQs)

#### Q1. Which model has a direct client-to-database connection?
---------------------------------------------------------------------------------------------
* A) 1-Tier Architecture
* B) 3-Tier Architecture
* C) 2-Tier Architecture
* D) Multi-Tier Architecture
* Correct Answer: C
* Reason: Client application directly talks to the database server.
---------------------------------------------------------------------------------------------

#### Q2. Which APIs connect client and server in 2-Tier setup?
---------------------------------------------------------------------------------------------
* A) HTML and CSS
* B) ODBC and JDBC
* C) HTTP and FTP
* D) SMTP and POP3
* Correct Answer: B
* Reason: ODBC and JDBC APIs link the client directly to the database.
---------------------------------------------------------------------------------------------

#### Q3. Which system uses an intermediate layer for processed data?
---------------------------------------------------------------------------------------------
* A) 1-Tier Architecture
* B) 2-Tier Architecture
* C) 3-Tier Architecture
* D) Single-Tier Architecture
* Correct Answer: C
* Reason: Application server acts as a medium between client and database.
---------------------------------------------------------------------------------------------

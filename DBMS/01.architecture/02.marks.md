### 📝 Section 2: 2 Marks (Precise Definitions)

#### Q1. Define 1-Tier Architecture.
---------------------------------------------------------------------------------------------
* It is a local system where user works directly with the database.
* The client, server, and database exist within a single application.
---------------------------------------------------------------------------------------------

#### Q2. What is a Database Schema?
---------------------------------------------------------------------------------------------
* It is a structural blueprint of tables, fields, and relationships.
* It maintains data consistency and secures the database structure.
---------------------------------------------------------------------------------------------

#### Q3. Define Tight Coupling in 2-Tier.
---------------------------------------------------------------------------------------------
* It means client application and database server depend heavily on each other.
* Any database structural change forces an update on the client side.
---------------------------------------------------------------------------------------------

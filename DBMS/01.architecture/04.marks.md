#### Q1. Detailed comparison between 2-Tier and 3-Tier Architecture.
---------------------------------------------------------------------------------------------
* 2-Tier Architecture consists of exactly 2 layers: Client and Server.
* 3-Tier Architecture contains 3 layers: Client, App Server, and Database.
* In 2-Tier, the client application connects directly to the database layer.
* In 3-Tier, the client connects to App Server, which accesses the database.
* Business logic in 2-Tier is stored inside the frontend client application.
* Business logic in 3-Tier is managed centrally within the Application Server.
* 2-Tier is less secure because the data tier is exposed to client machines.
* 3-Tier ensures high security by hiding the database behind the middle layer.
* Scalability is limited in 2-Tier as heavy user traffic slows down performance.
* Scalability is exceptionally high in 3-Tier using distributed servers.
* 2-Tier systems provide low deployment cost for small scale applications.
* 3-Tier systems involve high setup costs but handle complex web applications.

#### Q1. Differentiate between Referential Integrity and Entity Integrity with brief details.
---------------------------------------------------------------------------------------------
* Entity integrity specifies that the primary key column cannot accept empty or null values.
* Referential integrity dictates that foreign keys must match a valid referenced primary key.
* Entity integrity secures table rows, while referential integrity connects related tables.
---------------------------------------------------------------------------------------------

#### Q2. Explain Super Key and Candidate Key using an analytical comparison approach.
---------------------------------------------------------------------------------------------
* A super key is any attribute combination that uniquely identifies a row in a table.
* A candidate key is a minimal super key containing no extra or redundant attributes.
* Every candidate key is a super key, but every super key is not a candidate key.
---------------------------------------------------------------------------------------------

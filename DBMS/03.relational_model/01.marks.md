### 🎓 Section 1: 1 Mark (MCQs)

#### Q1. What term defines the total number of columns or attributes present in a relation?
---------------------------------------------------------------------------------------------
* A) Cardinality
* B) Domain
* C) Degree
* D) Tuple
* Correct Answer: C
* Reason: Degree represents the total count of attributes or columns inside a database table.
---------------------------------------------------------------------------------------------

#### Q2. Which integrity rule states that a Primary Key attribute can never contain a NULL value?
---------------------------------------------------------------------------------------------
* A) Referential Integrity
* B) Entity Integrity
* C) Domain Integrity
* D) User-Defined Integrity
* Correct Answer: B
* Reason: Entity integrity constraint explicitly dictates that primary keys cannot be null.
---------------------------------------------------------------------------------------------

#### Q3. What is a Candidate Key that contains no unnecessary or extra attributes called?
---------------------------------------------------------------------------------------------
* A) Super Key
* B) Minimal Super Key
* C) Foreign Key
* D) Secondary Key
* Correct Answer: B
* Reason: A candidate key is defined as the smallest or minimal possible super key set.
---------------------------------------------------------------------------------------------

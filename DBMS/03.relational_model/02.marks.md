### 📝 Section 2: 2 Marks (Precise Definitions)

#### Q1. Define the term Relation in the Relational Model.
---------------------------------------------------------------------------------------------
* A relation is a structured database table consisting of unique rows and columns.
* It is a mathematical concept based on set ideas to organize structural database records.
---------------------------------------------------------------------------------------------

#### Q2. What is Cardinality in a database table?
---------------------------------------------------------------------------------------------
* Cardinality refers to the total number of rows or tuples present in a relation.
* It changes dynamically as new records are inserted or deleted from the active table.
---------------------------------------------------------------------------------------------

#### Q3. Define the concept of Domain Constraint.
---------------------------------------------------------------------------------------------
* It defines the predefined set of valid values permitted for a specific attribute.
* It ensures all data values entered into a column share the exact same data type rules.
---------------------------------------------------------------------------------------------

### 🏛️ Section 4: 6 Marks (Detailed Theory)

#### Q1. Explain the fundamental properties and architectural rules of the Relational Model.
---------------------------------------------------------------------------------------------
* Every relation or table in the database must possess a completely unique name constraint.
* Each attribute or column must have a distinct name within that specific relation structure.
* All data values stored in cells must be atomic, meaning they are completely indivisible.
* Duplicate rows are strictly forbidden to ensure every single record stays unique.
* The sequential order of rows and columns holds no structural significance to the engine.
* Domain constraints enforce that column cells conform to specified shared data type rules.
* Every relation must establish a primary key to uniquely track down individual tuples.
* Null values are permitted to handle unknown data fields, excluding primary key fields.
* Entity integrity ensures core tracking keys are never empty during transaction processing.
* Referential integrity links child foreign keys accurately to parent primary key targets.

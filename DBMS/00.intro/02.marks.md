### 📝 Section 2: 2 Marks (Precise Definitions)

#### Q1. Define Data Independence.
---------------------------------------------------------------------------------------------
* It is the ability to change the database structure
* without affecting the application programs.

---------------------------------------------------------------------------------------------

#### Q2. What is a File System?
---------------------------------------------------------------------------------------------
* It is a traditional data storing method.
* Data is kept in separate files without relationships.

---------------------------------------------------------------------------------------------

#### Q3. Define the term Data.
---------------------------------------------------------------------------------------------
* Data is a collection of raw facts, figures, and values.
* It does not carry any context or meaning until it is processed.

---------------------------------------------------------------------------------------------

#### Q4. What is Data Integrity?
---------------------------------------------------------------------------------------------
* Data Integrity ensures stored data is accurate and consistent.
* It prevents invalid values, such as preventing negative marks.

---------------------------------------------------------------------------------------------

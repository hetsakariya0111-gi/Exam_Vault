### 🎓 Section 1: 1 Mark (MCQs)

#### Q1. Raw facts and figures without any context are called:
---------------------------------------------------------------------------------------------
* A) Information
* B) Database
* C) Data
* D) Metadata
* Correct Answer: C
* Reason: Data is unprocessed facts that lack meaning.

---------------------------------------------------------------------------------------------

#### Q2. Software used to manage databases efficiently is:
---------------------------------------------------------------------------------------------
* A) Operating System
* B) DBMS
* C) File System
* D) Text Editor
* Correct Answer: B
* Reason: A DBMS provides functions to create and manage data.

---------------------------------------------------------------------------------------------

#### Q3. Which type of data contains only two possible values, True or False?
---------------------------------------------------------------------------------------------
* A) Numeric Data
* B) Text Data
* C) Boolean Data
* D) Multimedia Data
* Correct Answer: C
* Reason: Boolean data type can only represent True or False values.

---------------------------------------------------------------------------------------------

#### Q4. Which rule states that a transaction's operations are all or nothing?
---------------------------------------------------------------------------------------------
* A) Consistency
* B) Isolation
* C) Atomicity
* D) Durability
* Correct Answer: C
* Reason: Atomicity ensures a transaction completes fully or rolls back completely.

---------------------------------------------------------------------------------------------

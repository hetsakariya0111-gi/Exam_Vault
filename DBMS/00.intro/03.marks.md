### 💡 Section 3: 3 Marks (Conceptual Breakdown)

#### Q1. Differentiate between Data and Information with an example.
---------------------------------------------------------------------------------------------
* Data consists of raw facts that have no meaning alone.
* Information is processed data that has clear context.
* Example: The number 95 is data.
* "Highest Marks = 95" is information.

-----------------------------------------------------------------------------------------------

#### Q2. Write the basic formula for Information and explain it with an example.
---------------------------------------------------------------------------------------------
* The basic working formula is: Data + Processing = Information.
* Data contains raw facts like student marks 85, 91, and 78.
* Processing counts these values to give a structured outcome.
* The output "Highest Marks = 91" is meaningful information.

---------------------------------------------------------------------------------------------

#### Q3. Explain Concurrency Control in a DBMS with a real-life scenario.
---------------------------------------------------------------------------------------------
* It allows multiple users to access a database at the same time.
* It prevents conflicts when changes are made simultaneously.
* Scenario: Two bank employees updating the same account at once.
* Concurrency control ensures both operations execute safely without errors.

### 🏛️ Section 4: 6 Marks (Detailed Theory)

#### Q1. Explain the problems of File Systems solved by DBMS.
---------------------------------------------------------------------------------------------
* File Systems cause high data redundancy.
* This means duplicate data is stored in multiple files.
* DBMS minimizes this redundancy to save storage space.
* File Systems lead to serious data inconsistency.
* Different files might contain conflicting information.
* DBMS maintains consistent data across all tables.
* File Systems offer very low security for raw records.
* Anyone can access the unsecured storage files easily.
* DBMS provides high security using access controls.

---------------------------------------------------------------------------------------------

#### Q2. Detailed comparison between traditional File Systems and modern DBMS.
---------------------------------------------------------------------------------------------
* File Systems store data in isolated text or document files.
* DBMS stores data systematically in electronic database structures.
* File Systems suffer from high data redundancy across records.
* DBMS minimizes data redundancy to save storage space.
* File Systems cause inconsistency where identical rows show different updates.
* DBMS maintains high data consistency using automated validation rules.
* File Systems provide poor data security for sensitive information.
* DBMS ensures high data security using user access permissions.
* File Systems do not support automated backup and recovery operations.
* DBMS creates regular backups and restores data after unexpected crashes.
* File Systems lack transaction control features for data safety.
* DBMS supports complex transactions using robust ACID property rules.

---------------------------------------------------------------------------------------------

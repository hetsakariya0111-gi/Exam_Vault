### 🎓 Section 1: 1 Mark (MCQs)

#### Q1. Which ER model symbol is used to represent a Weak Entity?
---------------------------------------------------------------------------------------------
* A) Rectangle
* B) Double Rectangle
* C) Diamond
* D) Double Oval
* Correct Answer: B
* Reason: A double rectangle uniquely identifies a weak entity in an ER diagram.
---------------------------------------------------------------------------------------------

#### Q2. What problem occurs when developers create database tables directly without ER modeling?
---------------------------------------------------------------------------------------------
* A) High security
* B) Data redundancy
* C) Fast query execution
* D) Efficient storage
* Correct Answer: B
* Reason: Skipping conceptual design leads to repeated data fields and inconsistency.
---------------------------------------------------------------------------------------------

#### Q3. Which attribute component uniquely identifies a strong entity?
---------------------------------------------------------------------------------------------
* A) Multivalued Attribute
* B) Derived Attribute
* C) Primary Key
* D) Partial Key
* Correct Answer: C
* Reason: A strong entity must possess its own primary key for independent identification.
---------------------------------------------------------------------------------------------

### 📝 Section 2: 2 Marks (Precise Definitions)

#### Q1. Define Entity Relationship (ER) Model.
---------------------------------------------------------------------------------------------
* It is a high-level conceptual data model used to design database structures.
* It visually represents data using entities, attributes, relationships, and constraints.
---------------------------------------------------------------------------------------------

#### Q2. What is a Weak Entity?
---------------------------------------------------------------------------------------------
* It is an entity that cannot be uniquely identified by its own attributes alone.
* It relies completely on a parent strong entity for its existence in the system.
---------------------------------------------------------------------------------------------

#### Q3. Define Database Design.
---------------------------------------------------------------------------------------------
* It is the planning process of organizing data fields and their relations before production.
* A good design ensures efficiency, eliminates redundancy, and maintains data accuracy.
---------------------------------------------------------------------------------------------
